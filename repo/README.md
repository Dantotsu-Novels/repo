# Dantotsu Novel Extensions Repository (Distribution Branch)

This branch contains the distributed index and compiled APK artifacts for Dantotsu Novel Extensions.

## Repository URL
Add this URL inside **Dantotsu** (More/Settings → Extensions → Novel Extensions → Add Repository):
```text
https://raw.githubusercontent.com/Dantotsu-Novels/repo/repo/repo/index.json
```

## Source Code
The source code and developer instructions are available on the [master branch](https://github.com/Dantotsu-Novels/repo).
